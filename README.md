# Kush Empire Enterprises — Web Task

This is a three-page HTML/CSS website created to match the assignment requirements.

## Files
- `index.html` — Home page
- `services.html` — Services page
- `contacts.html` — Contacts page
- `style.css` — Single external stylesheet used by all pages
- `assets/director-1.svg`, `director-2.svg`, `director-3.svg` — replaceable portrait placeholders

## Before submission
1. Replace the sample business name/content if your group selected a different business.
2. Replace the three sample director names, registration numbers and SVG portraits with your group's actual information.
3. Update the phone number, email and location.
4. Open `index.html` in a browser and test every navigation link.
5. Create a GitHub repository, upload all files, then enable GitHub Pages from the repository's Pages settings.

## GitHub Pages
The site uses only HTML, CSS and local SVG assets, so it can be hosted directly with GitHub Pages without a server.
